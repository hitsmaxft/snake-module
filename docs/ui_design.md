下面是 **纯 UI 规范**，已完全 **去除所有与车辆相关的描述**，只保留 **模块尺寸、坐标、字体大小、类型（文字/数字/图案）**。
用于 240×240 嵌入式圆形界面布局。

---

# **240×240 嵌入式屏幕 UI 规范（精简可移植版）**

## **0. 坐标说明**

* 坐标原点：(0,0) 在左上角
* 中心点：(120,120)
* 所有尺寸单位：像素(px)

---

# **1. 外层圆形结构**

### **1.1 外环（图案）**

* 类型：图案 / 圆环
* 外径：212 px（半径 106）
* 内径：188 px（半径 94）
* 圆心坐标： (120,120)

### **1.2 刻度圈（图案）**

* 类型：图案 / 刻度线
* 半径：90 px（刻度线长度跨 86–94 px 范围）
* 主刻度：长度 8 px，宽 2 px
* 次刻度：长度 4 px，宽 1 px
* 特定区段可染色（例如某段角度 300°–330°）
  → 类型：图案

---

# **2. 中央信息区（同心圆布局）**

## **2.1 主数字**

* 类型：数字
* 内容示例："39"
* 字号：48 px
* 对齐：水平居中
* 位置：中心上偏移 10 px

  * 推荐基准位置：文本中心约在 (120,110)

## **2.2 次级单位文本**

* 类型：文字
* 内容示例："km/h"（任意文字均可）
* 字号：18–20 px
* 对齐：水平居中
* Y 坐标：主数字下约 +24 px

  * 推荐位置：約 (120, 134)

---

# **3. 次级标签区**

## **3.1 中号文字（如模式、标签）**

* 类型：文字
* 字号：28 px
* 对齐：水平居中
* Y 坐标：位于单位文本下约 +26 px

  * 推荐位置：約 (120, 160)

## **3.2 小标签（例如小矩形文字条）**

* 类型：文字（可配背景色块）
* 字号：12–14 px
* 尺寸：高度 12–14 px，宽度随文本自动
* 对齐：水平居中
* Y 坐标：中号文字下约 +14 px

  * 推荐位置：約 (120, 174)

---

# **4. 辅助信息行**

## **4.1 小号文字提示**

* 类型：文字
* 字号：10–12 px
* 对齐：水平居中
* Y 坐标：标签区下约 +12 px

  * 推荐位置：約 (120, 188)

---

# **5. 小图标（图案）区域**

## **5.1 左右图标**

* 类型：图案 / 图标
* 图标尺寸：16×16 或 20×20 px
* 排布：以中心为参考点，角度 45° 或 315° 对称放置
* 距离中心半径：约 54 px

  * 左侧图标中心示例位置：
    (120 – 38, 120 – 38) → (82, 82)
  * 右侧图标中心示例位置：
    (120 + 38, 120 – 38) → (158, 82)

---

# **6. 背景区**

* 类型：图案 / 渐层色块
* 区域：圆形半径约 74 px 内（中心显示区）
* 用途：承载数字与文字，无特定内容要求

---

# **7. 可配置参数（可直接放入配置文件）**

```
center = (120,120)
outer_ring_outer_radius = 106
outer_ring_inner_radius = 94
tick_radius = 90
main_number_font = 48
unit_font = 18
label_font = 28
small_label_font = 12
info_font = 10
main_number_pos = (120,110)
unit_pos = (120,134)
label_pos = (120,160)
small_label_pos = (120,174)
info_pos = (120,188)
icon_radius = 54
icon_size = 16
```
